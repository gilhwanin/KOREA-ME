# 공고24 OPEN API 채용정보 자동 연동 시스템

본 저장소에는 **공고24 OPEN API를 활용하여 채용정보를 자사 데이터베이스에 자동 연동하는 API** 코드가 포함되어 있습니다. 
이 프로젝트는 OPEN API를 통해 채용 공고 데이터를 실시간으로 수집, 가공, 저장하며, Bubble.io와 연동하여 자사의 DB에 저장하고 웹 서비스에서 활용할 수 있도록 설계되었습니다.

※전체 서버코드는 보안상 공개하지 않습니다. 다만, 가장 기술적인 "채용정보 자동 연동" 부분만을 편집하여 공개합니다.
포트폴리오 용도로 업로드되었습니다.

## 개요
이 API는 다음과 같은 기능을 수행합니다:
- 공고24 OPEN API에서 최신 채용 정보를 수집
- 데이터 가공 및 MySQL 데이터베이스 저장
- Bubble.io와 연동하여 채용 공고를 실시간 반영
- 채용 마감 상태 자동 점검 및 업데이트

## 주요 기술
- **Python Flask** : API 서버 개발
- **MySQL** : 채용 데이터 저장 및 관리
- **Requests** : 외부 API 호출 및 데이터 처리
- **API** : Google Translation API, 공공포털 API 등의 외부 API를 활용하여 서비스 구현  
- **XML Parsing (ElementTree)** : OPEN API 응답 데이터 처리
- **Regex** : 채용 정보 가공 및 데이터 정제
- **Pyngrok** : 로컬 개발 환경에서 외부 API 호출 테스트 지원

## API 흐름
1. **채용 공고 수집**: OPEN API를 호출하여 XML 데이터를 받아옴
2. **데이터 가공**: 근무 조건, 기업 정보, 급여 정보 등을 정제 및 변환
3. **DB 저장**: 정제된 데이터를 MySQL에 저장
4. **Bubble.io 연동**: 저장된 데이터를 Bubble.io 웹 서비스에 전달
5. **채용 상태 점검**: ‘채용시 마감’ 공고의 상태를 주기적으로 점검하고 업데이트

## 라이선스
이 프로젝트는 포트폴리오 목적으로만 공개되었으며, 상업적 이용을 금합니다.
